# Project instructions

- For future bug fixes and changes, edit the Render deployment source under `server/` and the Godot client under `godot_client/` whenever the issue affects both sides.
- Do not modify `backend/`, `deno-server/`, `deploy_deno/`, or client/backup copies unless the user explicitly asks.
- After fixing a bug, run the relevant checks again; if another fix is needed, repeat until the checks are clean.
